# 🌱 محاكي دارة الري الأوتوماتيكية الذكية

> Smart Automatic Irrigation System Simulator

نظام ري ذكي تفاعلي يعتمد على الأردوينو وحساسات الرطوبة والمطر لري النباتات تلقائياً مع إمكانية التحكم عن بعد عبر IoT.

الصف التاسع أ - مدرسة عين منجد الثانوية

## ✨ المميزات

### 🎮 المحاكاة التفاعلية
- محاكاة بصرية حية لدارة الري
- تشغيل تلقائي ويدوي للمضخة
- وضع نهاري وليلي
- تأثيرات بصرية واقعية (مطر، شمس، نباتات)

### 📊 تحليل البيانات
- رسم بياني حي لكل القراءات
- إحصائيات مفصلة للنظام
- تصدير البيانات بصيغة CSV

### 🌐 IoT والتحكم عن بُعد
- محاكاة تطبيق موبايل
- اتصال MQTT
- تنبيهات Telegram
- رفع البيانات على ThingSpeak

### ⏰ الجدولة الذكية
- جدولة مواعيد الري
- ساعة حية
- مرونة في التحكم

### 🧮 حاسبة المياه
- حساب الاستهلاك اليومي/الشهري/السنوي
- حساب التكلفة (مياه + كهرباء)
- مقارنة مع الري التقليدي

### 💻 الكود
- كود Arduino كامل ومنظم
- كود ESP32 مع IoT
- محاكي Serial Monitor

## 🔧 المكونات المستخدمة

| المكون | الوظيفة |
|--------|---------|
| Arduino Uno R3 | المتحكم الرئيسي |
| حساس رطوبة التربة YL-69 | قياس رطوبة التربة |
| حساس المطر | كشف هطول الأمطار |
| DHT22 | قياس الحرارة والرطوبة |
| Relay Module 5V | التحكم بالمضخة |
| مضخة ماء 12V DC | ضخ الماء |
| LCD 16x2 I2C | عرض المعلومات |
| LEDs | مؤشرات الحالة |

## 📐 المخطط الكهربائي

المشروع يحتوي على مخطط كهربائي تفصيلي يوضح كل التوصيلات بين المكونات.

## 🎯 كيفية الاستخدام

1. افتح الرابط المباشر
2. اضبط الإعدادات (عتبة التشغيل، الإيقاف، إلخ)
3. شاهد المحاكاة تعمل تلقائياً
4. جرّب التبويبات المختلفة لاستكشاف كل الميزات
